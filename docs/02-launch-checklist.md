# 고객 사이트 납품 전 체크리스트

실제 고객 사이트를 공개하기 전에 하나씩 확인하세요.

## 계약·소유권
- [ ] 도메인은 **고객 명의**로 등록
- [ ] 계약서에 범위, 월 유지비 포함 항목, 코드·콘텐츠 소유권, 해지 조건 명시
- [ ] 사진·로고는 고객이 소유했거나 라이선스가 확인된 것만 사용

## 콘텐츠 정확성 (챗봇 책임 방지)
- [ ] `src/data/restaurant.ts`의 가격, 영업시간, 알레르기, 정책을 **사장님과 한 줄씩 확인**
- [ ] `isDemo: false`로 변경 (데모 배너와 검색엔진 차단 해제)
- [ ] 챗봇 테스트: 할인 요구, 예약 확정 요구, 메뉴에 없는 질문, "규칙 무시해" 같은 요청에 안전하게 답하는지
- [ ] 정책이 바뀌면 누가 언제 데이터를 업데이트할지 정하기 (월 유지관리에 포함)

## 개인정보 (BC PIPA / PIPEDA)
- [ ] 개인정보처리방침을 고객의 실제 처리 방식에 맞게 수정 (보관 기간, 담당자, 사용하는 외부 서비스)
- [ ] 개인정보 담당자 연락처 기재
- [ ] 서버 로그에 개인정보가 남지 않는지 확인

## CASL
- [ ] 마케팅 동의 체크박스가 기본으로 **체크 해제** 상태인지
- [ ] 동의 기록(시간, 문구) 저장 구현
- [ ] 발송하는 메일에 수신 거부 링크와 연락처 포함

## 보안
- [ ] `ANTHROPIC_API_KEY`는 호스팅 환경변수에만 넣기 (커밋 금지, `NEXT_PUBLIC_` 금지)
- [ ] Anthropic 콘솔에서 **월 사용량 상한** 설정
- [ ] 요청 횟수 제한을 공유 저장소(Upstash 등)로 교체 (서버리스 환경일 때)
- [ ] 스팸이 많으면 Cloudflare Turnstile 추가 (서버에서 토큰 검증)
- [ ] 보안 헤더 확인: `curl -I https://도메인`
- [ ] 외부 서비스(지도, 분석 도구 등)를 추가하면 CSP에 해당 도메인 추가

## 접근성·품질 (WCAG 2.1 AA 목표)
- [ ] 키보드만으로 모든 기능 사용 가능
- [ ] 이미지 대체 텍스트, 색 대비 확인
- [ ] 모바일 화면에서 가로 스크롤 없음
- [ ] Lighthouse 점수 확인 (성능, 접근성, SEO)

## 노출
- [ ] Google Business Profile의 정보(주소, 영업시간, 전화)를 웹사이트와 일치
- [ ] 구글 서치 콘솔 등록
